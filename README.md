# Commodity seasonality charts with LSEG Data Library for Python

This module allows the user to plot a seasonality chart for a futures contract in python with LSEG Data Library for Python. [Full article is provided here](https://developers.lseg.com/en/article-catalog/article/commodity-seasonality-charts-ldlib).

#### Pre-requisites:

LSEG Workspace with access to [LSEG Data Library for Python](https://developers.lseg.com/en/api-catalog/lseg-data-platform/lseg-data-library-for-python)

<b>Required Python Packages:</b> lseg-data, pandas, cufflinks, numpy
